# 冠唐云数据联动与新品利润试算自动匹配方案

文档版本：v0.1

状态：接口待确认、方案可实施

更新时间：2026-09-29

## 1. 结论

冠唐云可以成为网站的国内仓库权威数据源。公开官方资料已经确认其具备多仓库、货品、采购/销售订单、出入库、库位、批次、FIFO、库存查询和 Excel 导出等能力，这些数据足以支持：

- 国内库存实时或准实时同步。
- 出库 SKU 追溯到入库批次/采购订单。
- 当前仓库库存按订单或批次拆分。
- 新品利润试算自动获取采购成本、包装资料和箱规。

但在公开帮助中心和官网中没有找到可直接开发的 OpenAPI 端点、鉴权方式、限流、Webhook 或开发者控制台说明。因此当前结论是“业务上可以联动，技术接入方式需由冠唐确认”，不能在拿到官方接口资料前承诺实时 API 直连。

推荐实施顺序：

1. 冠唐官方只读 API/Webhook。
2. 冠唐标准 Excel/CSV 导出后由 NAS 定时导入。
3. 仅在私有部署且冠唐明确支持时使用只读数据库副本。

网页抓取或浏览器自动化不进入生产方案，因为页面结构、登录状态和权限变化会造成静默漏数，也难以审计。

## 3. 必须先向冠唐确认的问题

由管理员向冠唐客服或客户经理提交以下清单，并要求提供当前租户对应版本的正式文档：

1. 当前套餐是否支持第三方只读 API，是否需要升级或单独购买。
2. API 基础地址、鉴权方式、凭证申请、IP 白名单和凭证轮换方式。
3. 是否提供测试环境、接口限流、分页上限和历史数据保留范围。
4. 是否支持 `updatedAt`、增量游标或 Webhook。
5. 是否能读取货品、仓库、库位、采购订单、入库单、出库单、调拨、库存调整和当前库存。
6. 入库明细是否返回采购单号、批次号、仓库、库位、单位成本和审核状态。
7. 出库明细是否返回实际消耗的入库批次/采购单；若系统按 FIFO 计算成本，能否读取对应成本层分配。
8. 批次功能和库位功能是否已在当前租户启用。
9. 是否能区分物理在库、可用库存、待审核、待执行采购和已出库未交付。
10. 数据导出是否支持固定字段、定时任务或自动投递到指定目录。

在上述问题确认前，不创建冠唐 API 客户端，不在环境文件中加入猜测的端点或凭证变量。

## 4. 数据源职责

### 4.1 冠唐：国内仓实物账

- 货品编码、条码、名称、规格。
- 仓库和库位。
- 采购订单与供应商。
- 实际入库、批次、日期、数量和国内单位成本。
- 实际出库、目标/用途、日期和数量。
- 盘盈、盘亏、报废和调拨。
- 当前物理在库及批次余额。

### 4.2 积加：Amazon 经营账

- 市场、ASIN、MSKU 与平台 SKU 映射。
- 销售额、销量、售价、广告和退货。
- FBA/AWD 库存、跨境在途及 Amazon 接收。
- 平台费用和站点经营数据。

### 4.3 本站：关联、计算与审计

- 冠唐货品编码与 Amazon SKU/ASIN 的映射。
- 国内出库与跨境发货批次的关联。
- 入库批次余额、出库分配、未知来源和对账差异。
- 利润试算费率表、头程预设、来源标签和人工覆盖记录。

任何源系统事实都保留原始 ID、来源、同步时间和原始状态；本站修正不能覆盖原始值。

## 5. 数据口径与防重复规则

冠唐的“可用库存”可配置为包含待执行采购订单，所以不能直接作为国内实盘库存。网站需要分别保存：

```text
国内物理在库
待审核入库/出库
未完成采购
已出库待发运
跨境在途
FBA/AWD 库存
```

供应链总量不得把同一批货重复计入两个阶段。国内库存以冠唐已审核、已生效的物理库存为准；发货离开国内仓后从国内在库扣除，并转入跨境在途；Amazon 接收后再从在途转入 FBA/AWD。

批次余额公式：

```text
批次剩余 = 已审核入库 - 已分配出库 + 已生效库存调整
```

SKU 对账公式：

```text
所有批次剩余 + 未知来源库存 = 冠唐物理在库
```

差异必须进入异常中心，不得自动摊给最老或最新采购单。

## 6. 三种接入方式

### 6.1 方案 A：官方只读 API（首选）

同步顺序：货品与映射 → 仓库/库位 → 采购订单 → 入库 → 出库 → 调整 → 当前库存。首次全量同步后按更新时间或游标增量同步，至少每日做一次库存全量对账。

要求：

- 使用只读账号或只读应用权限。
- 凭证只保存在 NAS 环境变量或密钥存储，不进入 Git、镜像和浏览器。
- 保存游标、同步批次、接口响应摘要和失败重试记录。
- 删除/作废单据按状态同步，不物理删除历史事实。
- API 失败时保留上一次成功快照并显示数据过期，不回退为零。

### 6.2 方案 B：标准导出文件（可立即落地的兜底）

冠唐官方帮助文档确认出入库单和库位库存可以导出 Excel。由仓库管理员按固定模板导出到 NAS 的导入目录，网站识别文件类型并执行校验、预览和发布。

最少需要以下文件：

- 货品主数据。
- 仓库/库位库存。
- 入库单主表和明细。
- 出库单主表和明细。
- 批次库存或批次有效期明细。
- 库存调整/盘点明细。

导入必须检查列头版本、单据号唯一性、SKU 映射、审核状态、数量合计和库存对账。先生成预览，确认后发布新数据版本；失败不得覆盖当前生产快照。

### 6.3 方案 C：只读数据库副本（条件式）

仅适用于私有部署且冠唐提供正式数据字典、升级兼容承诺和只读副本。SaaS 账号不尝试直接连接数据库。

## 7. 供应链追溯落库

网站继续使用现有事件模型：

- `purchase_order_line`
- `warehouse_receipt`
- `warehouse_outbound`
- `outbound_allocation`
- `inventory_adjustment`
- `inventory_lot_balance`

关联优先级：

1. 冠唐出库明细直接返回入库批次/采购单。
2. 入库、出库和跨境发货存在同一业务单号或自定义字段。
3. 同仓库、同 SKU 按实际入库时间执行 FIFO 推算。
4. 管理员人工确认。
5. 无法分配时保留“来源待核对”。

建议在冠唐单据自定义字段中统一记录 `Amazon 发货批次号`、`目标市场`、`采购订单号`，能显著减少本地推算。

## 8. 新品利润试算：市场和类目之后自动匹配

### 8.1 页面流程

1. 选择市场：US（默认）、CA、MX。
2. 选择 Amazon 类目。
3. 可选：选择已有 SKU/ASIN 或相似 SKU。
4. 系统自动填充可确认字段，只展开仍缺失或低置信度的字段。
5. 用户确认后计算利润，不写回冠唐或积加。

### 8.2 自动匹配优先级

```text
明确选择的 SKU/ASIN
→ 同型号或同父体
→ 同类目、同尺寸/重量区间的相似 SKU
→ 市场与类目默认值
→ 要求用户输入
```

同一字段出现多来源冲突时：

- Amazon 售价和平台包装数据优先使用积加最新有效记录。
- 国内采购成本和箱规优先使用冠唐最新已审核记录。
- 管理员锁定值优先于自动匹配，但必须显示锁定人和日期。
- 相似 SKU 只提供估算，不自动替代真实主数据。

### 8.3 字段来源

| 字段 | 自动来源 | 匹配条件 | 无法匹配时 |
| --- | --- | --- | --- |
| 币种 | 市场配置 | 市场 | 不需输入 |
| 当前/参考售价 | 积加 | 市场 + SKU/ASIN | 用户输入 |
| Amazon 类目 | 积加/用户选择 | 市场 + ASIN | 以用户选择为准 |
| 采购成本 | 冠唐 | 冠唐货品编码 + 最新有效入库/主数据 | 用户输入 |
| 单品尺寸、重量 | 积加，本站主数据兜底 | 市场 + SKU/ASIN | 用户输入或选相似 SKU |
| 箱规、箱尺寸、箱重 | 冠唐，本站主数据兜底 | 冠唐货品编码 | 用户输入或选相似 SKU |
| Amazon 佣金 | 版本化费率表 | 市场 + 类目 + 售价 + 生效日期 | 阻止计算并提示缺费率 |
| FBA 配送费 | 版本化费率表 | 市场 + 尺寸分段 + 计费重量 + 生效日期 | 阻止计算并提示缺参数 |
| 头程 | 本站运输预设 | 市场 + 运输方式 + 箱规/箱重 | 用户选择方案或输入 |
| 广告 | 默认参数 | 售价 × 15% | 可在高级参数修改 |
| 退货 | 默认参数 | 售价 × 1% 或配置公式 | 可在高级参数修改 |
| 税率 | 默认参数 | 0% | 可在高级参数修改 |

危险品和电池附加费不计算。结果页必须明确显示这一排除项，避免将普通测算误用到特殊商品。

### 8.4 市场和类目不能替代的输入

仅选择市场和类目不足以得到真实利润：佣金可能依赖售价，FBA 配送费依赖包装尺寸和计费重量，头程依赖箱规和箱重，利润还需要采购成本。为了“尽量自动”但不制造假数据：

- 已有 SKU：大部分字段可自动带入，用户只需确认或调整售价场景。
- 全新品：用户至少输入售价、采购成本和包装资料，或明确选择相似 SKU 估算。
- 缺少关键字段时显示“待补充”，不使用 0 或隐含默认值继续计算。

### 8.5 来源与可信度展示

每个字段显示：

```text
值 + 单位 + 来源 + 数据日期 + 置信度 + 是否可编辑
```

来源标签包括：冠唐、积加、Amazon 费率表、本站预设、相似 SKU 估算、手工输入。费率规则保存市场、类目、版本、生效日期和失效日期；跨市场或过期规则不得静默复用。

## 9. 分阶段实施

### P0：确认接入与口径

- 向冠唐获取当前租户的正式接口/导出文档。
- 确认批次、库位、API 权限和费用。
- 固化冠唐货品编码与本站 SKU/ASIN 映射。
- 配置物理库存、可用库存和单据状态口径。

### P1：先用导出跑通

- 建立冠唐标准文件导入、预览、校验和版本发布。
- 完成国内库存和出入库同步。
- 建立批次余额与库存对账。
- 计算器先读取冠唐导入快照和积加数据。

### P2：切换官方 API

- 保持同一内部事件模型，只替换采集适配器。
- 增量同步单据与库存，每日全量对账。
- Excel 保留为故障兜底，不形成第二套业务口径。

### P3：提高自动匹配率

- 统计每个计算器字段的自动匹配率和人工修改率。
- 优先修复 SKU 映射、箱规和成本缺失。
- 只有在历史数据足够时启用相似 SKU 建议。

## 10. 验收标准

- 冠唐物理在库与网站国内库存按仓库、SKU 对账，差异可见且不静默摊销。
- 出库 SKU 能显示采购单/入库批次来源，无法直接关联时明确标记 FIFO 推算。
- “可用库存”中的未到仓采购不会计入物理在库。
- 同一批货不会同时计入国内库存和跨境在途。
- 计算器切换 US、CA、MX 后使用对应币种和费率版本。
- 选择类目后使用该市场对应的佣金规则。
- 选择已有 SKU 后可自动带入售价、成本、尺寸重量和箱规；每个值都有来源和日期。
- 全新品缺少关键输入时停止计算，不把缺失值当作 0。
- 广告默认 15%、退货默认 1%、税率默认 0%，危险品和电池附加费明确排除。
- 任何同步或计算失败都保留上一次有效数据并显示错误，不返回“无数据”或全零结果。
